# 会话检索集成方案

> 把本仓库的库内检索与实时问股开放给外部 agent 会话（飞书 bot、ZCode/traecli 终端会话）与无人值守脚本使用。2026-11-12 实施。
> 关联文档：[关键词问答技术方案.md](关键词问答技术方案.md)（ask 链路本身）· fupange 工作区根 `AGENTS.md`「资讯检索（韭研热点）」节（会话侧路由规则）。

## 1. 集成形态

三个入口共用同一套 CLI，不新增常驻服务与网络端点：

| 使用方 | 入口 | LLM 来源 |
|---|---|---|
| 飞书 bot 会话（traecli lark channel，工作区 14.fupange） | 技能 `jiuyan-news` → `npm run search` / `npm run ask` | 会话自身（handoff 自回填） |
| ZCode / traecli 终端会话 | 全局技能 `~/.zcode/skills/jiuyan-news` | 会话自身（同上） |
| 脚本 / cron（无人值守） | 技能目录 `scripts/ask_unattended.sh` | `traecli exec` 非交互（GLM-5.3，仅文件读写） |

被否掉的形态：常驻 HTTP 服务（进程守护+端口负担，违背最小实现）；MCP server（双 runtime 注册维护成本高于收益）；把 traecli 包成 OpenAI 兼容端点喂 `GLM_BASE_URL`（traecli 无 HTTP 端点形态）。

## 3. handoff 自回填（会话内）

`.env` 未配 `GLM_API_KEY` 时 ask 走 handoff：任务落盘 `data/llm-tasks/`，由**调用方会话**充当模型回填（飞书 bot 会话、ZCode 会话均为此模式；每日管线的 score/cluster/write/theme 同理由 ZCode 定时任务回填）。流程：

1. `npm run ask -- --keyword=xx` → 输出 `awaiting_handoff` 并列出任务文件；
2. 会话读任务文件，按内嵌 prompt/agentInstructions 写 `data/llm-results/` 同名结果；
3. `npm run ask -- --consume` 回填续跑，可能派生 `_r2`（回到 2），`done` 时渲染结论卡。

铁律（consume 校验强制）：outputs 的 id/batch 原样复制；ask-aggregate 的 outputs 为单元素数组；任务/结果同名配对。会话内**禁止嵌套调 traecli** 回填（徒增延迟与失败面）。

2026-11-12 实测（佳力图）：crawl → r1 回填 → consume 抓全文派生 r2 → 回填 → consume 出完整结论卡，全链路通。

## 4. 无人值守回填器

`~/.zcode/skills/jiuyan-news/scripts/ask_unattended.sh <关键词> [--no-crawl]`：

- 待处理任务**只认 ask CLI 输出列出的文件**（`awaiting_handoff` 清单）与输出中 `ask#id` 名下无结果的任务，不盲扫任务目录——避免捞到历史遗留任务；
- 每个任务用 `traecli exec -m <模型> --permission-mode bypass_permissions -C <仓库根> -`（提示词走 stdin，任务文件路径在内）回填，循环 consume 到 done；回填模型默认 内部-Deepseek-V4.1-Flash-1017（2026-11-12 用户指定），`JIYAN_FILL_MODEL` 可覆盖；
- 凭据：`~/.config/trae-cli/credentials.env`（PAT，600）；
- 回填失败保留现场退出非零，可进会话接管手工回填。

注意 traecli 版本差异：本机版本非交互入口是 `exec` 子命令（`-p` 是 `--profile` 短选项，不是提示词参数）。

## 5. 会话侧规则（fupange 根 AGENTS.md 同步登记）

- 技能 `jiuyan-news` 挂 `~/.zcode/skills/`（全局）+ 14.fupange `.trae/skills/` 符号链接（bot 会话可见）；
- 路由：热点榜/题材/复盘 → search；个股/概念实时消息面 → ask；战法 → fupan-ge-wiki；行情 → ifind；
- 边界：会话只处理 `ask-*` 任务文件；禁止跑 crawl/push 等管线阶段；不改本仓库代码与配置（ask 设计内写库除外）；
- fupange 根「检索边界」（禁读工作区外目录）对本节两条命令设唯一豁免，其余禁令不变。

## 6. 风险与演进

- **耗时**：ask 会话内自回填约 1~3 分钟（含爬取礼貌间隔）；若需压缩，在 `.env` 配 `GLM_API_KEY`（glm-4-flash 免费档）即切直调一条命令完成，三入口无需改动；
- **LIKE 搜索无分词**：多词组合查询不支持，后续可上 FTS5；
- **无人值守回填质量**：依赖 traecli 会话按任务自描述产出合法 JSON，consume 校验失败即保留现场，不静默丢；
- detail 阶段接入定时编排后，`item_details` 全文覆盖面扩大，search 全文命中率随之提升（该工作在途，见仓库未提交改动）。
