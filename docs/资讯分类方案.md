# 资讯分类方案

> 回答三个问题：**这条资讯属于什么题材？值不值得入选？题材内哪些个股最重要？**
> 代码入口：`packages/core/src/taxonomy.ts`（分类）· `packages/core/src/stages/themes.ts`（题材聚合）· `industry/selection.ts`（门槛）· `industry/prompts/`（提示词）

## 1. 三级内容层级

```
条目 item（一篇帖子）
  └─ 事件 event（同一具体事件的多篇帖子合一，代表帖出面）
       └─ 题材 theme（同分类的多个事件聚合，催化逻辑综述 + Top5 概念股）
```

- 条目 → 事件：聚簇阶段（见[内容检索提炼方案](内容检索提炼方案.md) §3.3）
- 事件 → 题材：theme 阶段，按 taxonomy 分类聚合，每次推送前用 24h 窗口重建当日题材

## 2. 入选门槛（分级）

| 级别 | 判定依据（作者徽章） | 门槛 | 依据 |
|---|---|---|---|
| T1_5 | 机构 / 游资 / 公社达人 / 大神等 | 双次打分均分 ≥ **65** | 准官方信源，历史质量高 |
| T2 | 普通用户（含无徽章） | 双次打分均分 ≥ **76** | 偏严：宁少勿滥 |

- 双次独立打分取均值过线（AIHOT 同款，抑制单次抖动）
- **政策与宏观类默认压 15 分**（部委政策/央行动向/宏观数据/外围市场），除非直接改变板块预期
- 配置位置：`industry/selection.ts` 的 `THRESHOLDS`

### 3.1 判定算法：概念关键词加权计分

优先级：**概念计分 > 驱动类型 > 行业 > 其他**

```
score(分类) = Σ 关键词长度（对每个命中标签累加，越长越具体权重越高）
```

为什么不用简单子串匹配：`"物理AI"` 包含 `"AI"`，会把 Optimus 事件误归 AI 类。加权后：
- 机器人事件 tags=[人形机器人,Optimus,物理AI]：robot 得 3+7+3=13 分，ai 仅 2 分 → robot ✓
- `"太空算力"`(4字) 归 AI·算力（4>2 压过 space 的 `"太空"`），`"太空光伏"`(4字) 归新能源 ✓

### 3.2 调整方法

改 `packages/core/src/taxonomy.ts` 的 `CATEGORIES`（label/emoji/keywords/indicators），跑 `npm test` 里的 taxonomy 用例回归。分类在网站首页、飞书卡片、题材聚合三处共用同一份。

## 4. 题材聚合（theme 阶段）

每次推送前把 24h 窗口内事件按上述分类聚成题材，产出：

1. **热度合计** = Σ 成员事件热度
2. **Top5 概念股**：`个股得分 = Σ(所在事件热度 + 代表帖评分×0.5)`，按得分降序取 5，并列看提及数——多事件提及的标的天然靠前
3. **催化逻辑综述**（事件数 ≥2 的题材）：LLM 按 `industry/prompts/theme.md` 生成 2 句 ≤80 字——"题材正在发生什么（把多事件催化串成逻辑链）+ 为什么是现在（边际变化/密集窗口/分歧提示）"，禁止编造、不写荐股语

存储：`themes` 表按 `(北京日期, 分类)` 重建（见[新鲜度方案](新鲜度方案.md) §4）。

## 5. 推送呈现

飞书卡片 = 题材优先（上限 5 题材 × 3 增量事件 + "其他动态"兜底）：

```

长征十二号批量组网叠加 StarMind 27Q3 时间表，商业航天进入密集催化窗口…
🎯 Top: 西部材料 · 润贝航科 · 钧达股份 · 久之洋 · 顺灏股份
1. 长征十二号发射… 评分77 🔥48
   长征十二号成功发射29组卫星… 🔗原帖
```

## 6. 已知边界

- 题材 = taxonomy 分类的粒度；若需要更细的"概念子簇"（如 AI 下的"光模块/国产算力"分列），在 theme 阶段加概念二级分组即可，算法位已预留（`buildThemes` 输入含 tags）
- 单事件题材不生成 LLM 综述（`needsLogic=false`），直接以事件摘要呈现
